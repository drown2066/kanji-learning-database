# Kanji Learning Database

A data-driven project for learning and analyzing Japanese kanji.

## Project goals

- Build a structured database of the 2,136 Jōyō kanji
- Store kanji meanings and readings
- Connect kanji with vocabulary
- Analyze kanji by difficulty, frequency, JLPT, and Kanken level
- Track personal learning progress

## Technologies

- Python
- SQL
- SQLite
- Pandas
- Git
- GitHub
